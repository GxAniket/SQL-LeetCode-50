# 🚀 LeetCode SQL 50 Solutions

A curated collection of solutions for the **LeetCode SQL 50 Study Plan**, designed to strengthen SQL fundamentals and prepare for technical interviews.

* **Aggregate Functions**
* **Subqueries**
* **Date Functions**
* **String Functions**
* **Interview-Oriented SQL Problems**
